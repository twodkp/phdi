Import JSON Format Example

The import file must be a valid JSON file formatted as an array of section objects containing text notes or local file paths: 

[
  {
    "id": "sec-1700000000000",
    "title": "Coursework Documents",
    "sources": [
      {
        "id": "src-1700000000001",
        "type": "file",
        "title": "Document Title",
        "path": "C:\\Path\\To\\Your\\File.pdf",
        "createdAt": "2026-08-03T10:00:00.000Z"
      },
      {
        "id": "src-1700000000002",
        "type": "text",
        "title": "Important Reminders",
        "content": "Submit research proposal before Friday.",
        "createdAt": "2026-08-03T10:05:00.000Z"
      }
    ]
  }
]
